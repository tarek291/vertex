## Sanity Studio

The content model lives in a standalone Studio workspace under [`studio/`](studio/).

```bash
cd studio
npm install
npm run dev      # Studio on http://localhost:3333
```

Env: the Studio loads the repo-root `.env.local` (`SANITY_STUDIO_PROJECT_ID`,
`SANITY_STUDIO_DATASET`). The web app needs `SANITY_API_READ_TOKEN` (server-only,
Viewer role) to read the private dataset. See [`.env.example`](.env.example).

After changing the schema or any GROQ query, regenerate types:

```bash
cd studio && npm run typegen   # writes ../sanity.types.ts
```

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
